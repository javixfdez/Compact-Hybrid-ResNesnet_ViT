# Compact-Hybrid-ResNesnet_ViT
This work proposes a lightweight hybrid ResNet-ViT featuring Bi-Directional Cross Guidance (BDCG) fusion and a Prototype-Anchored Similarity Head (PASH) effectively evaluated on PatchCamelyon dataset, including normal- isation, data augmentation and CLAHE enhancement. The final model achieved a ROC-AUC of 0.9791.
